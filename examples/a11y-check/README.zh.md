# 无障碍创作样例

这是用于说明证据边界的合成样例，不代表任何生产页面的无障碍结论。

1. 启用 `a11y_check`，把本目录加入 `authoring.allowedRoots`，并保留默认的 `approval` 访问模式。
2. 检查 `before.html`。确定性报告会列出缺陷、引擎与配置的精确版本、标准映射，以及仍须人工完成的检查。
3. 请 DSH 解释结果并提出修复建议。解释和修复建议来自模型，与确定性检测证据分开。
4. 人工审阅建议。只有在你决定修改时，才通过 DSH 常规 edit/write 工具及其审批策略执行；`a11y_check` 本身不能写文件。
5. 检查 `after.html`。静态检查通过仅表示：固定版本的自动规则集没有在这份输入源码中发现问题。
6. 对真实页面进行渲染，并执行版本化的键盘、浏览器/辅助技术和残障用户任务协议，之后才能提出更广泛的支持声明。

不要把私有源码上传为“证据”。应使用脱敏或合成样例，并记录引擎标识、配置版本、命令/工具输入、结果以及实际执行过的证据类别。
